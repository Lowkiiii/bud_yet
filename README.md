# Budyet 💸

A personal finance tracking and budgeting web application built using **Laravel PHP**.  
Budyet was developed to help individuals easily manage their expenses, monitor their cash flow, and take control of their financial wellness.

🔒 **Note:** The code for this project is private. Please contact me if you’d like to see a technical breakdown or a live demo.

---

## 💡 Project Overview

Budyet offers a user-friendly interface for managing personal income and expenses. The application supports account creation, detailed tracking of daily financial activities, and generates statistics of monthly expenses.

---

## 🔑 Features

- 🧾 **Expense & Income Logging**  
  Add, edit, and categorize transactions with amount, date, and purpose.

- 🔐 **User Authentication**  
  Secure login system with Laravel Breeze.

- 🏦 **Account Management**  
  Support for multiple financial accounts (cash, savings, etc.).

- 📆 **Monthly Budget Planning**  
  Set and track monthly budgets by category (e.g., food, transport, bills).

- 🗃️ **Transaction Microservices**  
  Laravel-based services handling CRUD operations efficiently.

---

## 🧰 Tech Stack

- **Backend:** Laravel 10 (PHP)
- **Frontend:** Blade templating, Bootstrap
- **Database:** MySQL
- **Authentication:** Laravel Breeze
- **Reporting:** Chart.js
- **Version Control:** Git, GitHub
